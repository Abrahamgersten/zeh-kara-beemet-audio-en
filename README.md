# zeh-kara-beemet-audio-en

English episode recordings of the site "זה קרה באמת" (https://abrahamgersten.github.io/zeh-kara-beemet/en/).

They were moved here on 2026-11-10 because the site passed GitHub Pages' 1 GB limit. The site's English page
(`en/js/app.js`, `audioUrl()`) plays them from https://abrahamgersten.github.io/zeh-kara-beemet-audio-en/<file>.mp3 .

On Avraham's computer the site folder `assets/audio/en` is a junction to this folder, so every tool keeps its old path.
A new or changed English recording must be committed and pushed HERE (the site repo ignores that folder).
